# SPHERE Forecasting Competition Data Processing pipeline

This repository hosts the scripts necessary to generate the data for the SPHERE Forecasting Competition.

## Installation

Clone the repository and navigate into the project directory:

```bash
git clone git@github.com:niklz/sphere_contest_data.git
```

*(Note: There is no project environment for this project at this stage. A list of required packages can be found in the `R/00_librariers.R` script, and this code will run using R version 4.5.1).*


## Usage

The data pipeline is  broken into enumerated modules (`00_..R`, `01_..R`, etc.) and should be exceuted in that order.
